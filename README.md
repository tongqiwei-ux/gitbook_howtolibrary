# 如何利用图书馆进行心理学研究——潘菽图书馆使用指南

### 序

图书馆无论如何转变服务形态和业务范围，在本质上，都是一个信息管理的单元。但是，信息的内涵在不断地扩展。在我所经历的时代变化上看，从2000年，图书馆逐步进入数字图书馆时代，主要的转变是从过去的印本文献管理，扩展到以数字文献管理为主的时代。2010年以后，图书馆进入到知识服务的时代，强调图书馆在印本文献和数字文献的整合上，进行知识加工和生产，不少图书馆开设了情报服务业务，不在仅仅是帮助科研人员找到文献就算结束，还要对现有海量文献进行整合和分析。2020年以后，数据成为图书馆的热门话题。图书馆的信息管理视角进一步扩展。从细粒度上看，数据是更为基础的信息单元，数据上可以产生文献，文献上可以产生知识。因此，在我的分析视角中，数据、文献和知识是从低到高，逐步综合的信息。

换一种取向来看，还有不同的角度：“由外而内” 与 “由内而外”。
